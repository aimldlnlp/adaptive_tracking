# Latin Modern Roman 10

Unmodified regular, bold, and italic OpenType fonts used for reproducible figures
and video typography. The optical design is Roman 10; display size is chosen for
readability at 1080p.

Authors: Bogusław Jackowski and Janusz M. Nowacki.
Source: https://www.gust.org.pl/projects/e-foundry/latin-modern
